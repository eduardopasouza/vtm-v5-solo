# Aventura: A Noite do Artigo

## Dados

| Campo | Valor |
|-------|-------|
| **História** | A Primeira Rachadura |
| **Partida** | A Coroa de Cinzas |
| **Duração estimada** | 1-3 sessões |
| **Status** | **CONCLUÍDA — Sucesso** |

## Resumo e Objetivo

Edward está no Elísio quando Old Gideon traz a notícia: um jornalista do *Times* está investigando ataques noturnos no East End, e seus rascunhos contêm um esboço que se parece com uma alimentação vampírica. Valerius exige ação imediata. Ashworth se voluntaria — e responde como sempre: força bruta.

**Objetivo:** Obter informações que Ashworth não conseguiu e demonstrar isso perante a corte ou aliados-chave.

## Cenas Planejadas

### Cena 1 — O Elísio
| Campo | Valor |
|-------|-------|
| **Local** | Holland House, Kensington |
| **Propósito** | A notícia chega. Ashworth se compromete. Edward observa e decide agir. |
| **NPCs** | Valerius, Anne Bowesley, Lord Ashworth, Old Gideon, Lady Marguerite, outros |
| **Testes prováveis** | Percepção (Raciocínio + Insight) para ler reações; Etiqueta para intervir sem parecer oportunista |
| **Decisão do jogador** | Como reagir à notícia? Observar em silêncio, oferecer ajuda, ou buscar Gideon em particular? |

### Cena 2 — A Negociação
| Campo | Valor |
|-------|-------|
| **Local** | Encontro privado com Old Gideon (local a definir — esgoto, taverna, cemitério) |
| **Propósito** | Edward compra a informação completa: quem é o jornalista, o que ele sabe, onde investiga |
| **NPCs** | Old Gideon |
| **Testes prováveis** | Manipulação + Persuasão para negociar preço; Raciocínio + Insight para avaliar se Gideon esconde algo |
| **Decisão do jogador** | Quanto pagar? Em moeda, favores, ou informação? Confiar em Gideon? |

### Cena 3 — O East End
| Campo | Valor |
|-------|-------|
| **Local** | Whitechapel / Spitalfields — ruas escuras, becos, tavernas |
| **Propósito** | Investigação pessoal: a cena do incidente, testemunhas mortais, rastros sobrenaturais |
| **NPCs** | Mortais (testemunhas), possível encontro com o jornalista ou o responsável pelos ataques |
| **Testes prováveis** | Raciocínio + Investigação para analisar a cena; Auspícios para percepção sobrenatural; Ofuscação para se mover sem ser notado; possível teste de Fome se a oportunidade de se alimentar surgir |
| **Decisão do jogador** | Quão fundo investigar? Confrontar testemunhas ou apenas observar? Usar Disciplinas em mortais? |

### Cena 4 — O Retorno
| Campo | Valor |
|-------|-------|
| **Local** | Escritório de Edward em Clerkenwell / ou corte |
| **Propósito** | Edward processa o que descobriu. Primeiro movimento político — compartilhar informações com um aliado-chave. |
| **NPCs** | James Harker (carniçal), Anne Bowesley, ou outro Primogênito |
| **Testes prováveis** | Manipulação + Política para posicionar a informação corretamente; Carisma + Persuasão se confrontar Ashworth |
| **Decisão do jogador** | Com quem compartilhar? Como apresentar as descobertas? Enfrentar Ashworth diretamente ou minar por trás? |

## Condições

| Tipo | Condição |
|------|----------|
| **Sucesso** | Edward obtém informações que Ashworth não tem e demonstra isso a pelo menos um membro da corte |
| **Sucesso parcial** | Edward obtém informações mas não consegue usá-las politicamente ainda |
| **Falha** | Edward é pego investigando sem autorização, ou Ashworth resolve a crise primeiro |
